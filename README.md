# Feedback de TurnoPlace

Acá se reportan errores y se piden mejoras de [TurnoPlace](https://turnoplace.com), tanto si jugás y reservás canchas como si tenés un club.

## Cómo mandar algo

- **[Reportar un error](https://github.com/TurnoPlace/feedback/issues/new?template=bug_report.yml)**: algo no anda como debería.
- **[Pedir una mejora](https://github.com/TurnoPlace/feedback/issues/new?template=feature_request.yml)**: algo que te gustaría que TurnoPlace hiciera.

Para escribir hace falta una cuenta de GitHub, que es gratis. Si no tenés una o preferís no crearla, escribinos a **turnoplace@gmail.com**.

## Antes de mandar

**Todo lo que se escribe acá es público.** No pongas tu celular, tu mail, el código de tu turno ni datos de otras personas: con el código de un turno se puede ver la reserva. Si para explicarlo hace falta algo de eso, mandalo por mail.

Si tu pedido ya está, sumale un 👍 en vez de abrir otro: así sabemos qué es lo que más se pide.

## Qué pasa después

Leemos todo. Los errores se arreglan primero; las mejoras se ordenan por cuánta gente las pide y cuánto ayudan. Cuando algo sale, lo cerramos con un comentario.
